GITHUB PAGES YÜKLEME
1) ZIP dosyasını bilgisayarında bir klasöre çıkart.
2) GitHub deposundaki eski web dosyalarını önce yedekle.
3) ZIP içindeki DOSYALARI (ZIP'in kendisini değil) repo ana dizinine yükle.
4) index.html, devlet.html, tarihce.html, iletisim.html ve assets klasörü aynı ana dizinde olmalı.
5) GitHub Pages ana sayfa olarak sadece ana dizindeki index.html dosyasını kullanır.
